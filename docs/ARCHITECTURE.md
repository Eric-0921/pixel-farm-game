# 像素农场 - 架构设计文档

## 1. 项目概述

像素农场是一款像素风格的种菜小游戏，核心玩法聚焦种植、浇水、收获。架构设计预留社交模块和通知系统的扩展接口。

## 3. 核心设计原则

### 3.1 前后端分离
- 前端：纯静态文件，通过 API 与后端通信
- 后端：REST API + WebSocket，无状态服务设计

### 3.2 实时同步
- WebSocket 用于实时推送（作物成熟通知、好友动态）
- HTTP 用于请求/响应式操作（登录、种植、收获）

### 3.3 可扩展性
- 通知系统采用抽象接口 + 提供者模式
- 社交模块预留数据结构和 API 路由
- 作物系统支持动态添加类型

## 5. 扩展指南

### 5.1 添加新的通知渠道
1. 在 `server/notifications/` 下创建新的 Provider 文件
2. 实现 `send(userId, notification)` 方法
3. 在 `server/index.js` 中注册：`notifier.registerProvider('channelName', provider)`

### 5.2 添加社交功能
- 好友系统：已有 `friends` 表和基础 API，可扩展聊天、访问农场等
- 交易/赠送：新增 `trades` 或 `gifts` 表
- 排行榜：新增 `leaderboard` 服务，按金币/经验排序

### 5.3 添加新作物
- 直接在 `crop_types` 表中插入新记录
- 前端渲染器会自动根据颜色和阶段数绘制
