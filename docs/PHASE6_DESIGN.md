# Phase 6 - 真实感生态模拟：视觉设计文档

## 文档信息

- **版本**: v1.0
- **目标**: 为前端开发者提供 Phase 6（真实感生态模拟）的详细视觉规范
- **适用范围**: 像素小人、作物图案、土壤状态、动画效果、粒子系统、雨天特效
- **画布规格**: 320×240 像素，`image-rendering: pixelated`

### 1.5 空闲动画

| 动画 | 触发条件 | 参数 |
|------|---------|------|
| **呼吸** | 始终进行 | 每 2000ms：`scaleY` 1.0 → 1.05 → 1.0，缓动 `ease-in-out` |
| **眨眼** | 每 3–5 秒随机 | 眼睛像素行（行 3）变为 `▓▓▓▓` → `████`（闭眼，200ms）→ 恢复 |
| **伸懒腰** | 连续 10 秒无操作 | 双臂上举（持续 800ms），然后恢复 |
| **看天** | 雨天自动触发 | 头部像素整体上移 1px，模拟抬头 45° |
| **撑伞** | 雨天 + 行走时 | 头顶出现像素伞，不影响移动速度 |

## 2. 作物图案设计规范

### 2.1 设计原则

1. **像素风格统一**：所有作物使用 8×8 或 8×16 像素绘制
2. **辨识度优先**：每种作物在 8×8 格内必须能一眼认出
3. **形态变化**：生长过程不仅是放大，而是**形态演变**
4. **成熟诱人**：成熟阶段增加光泽、色彩饱和度

## 3. 土壤状态视觉规范

### 3.1 土壤状态表

| 状态 | 底色 | 纹理颜色 | 纹理描述 | 作物影响 |
|------|------|---------|---------|---------|
| **干燥** | `#C4A35A` | `#8B7355` | 2–3 条随机裂纹 | 作物颜色偏黄（饱和度 -30%） |
| **正常** | `#8B6914` | — | 无额外纹理 | 正常显示 |
| **湿润** | `#5C4033` | `#6B8E23` | 3–5 个随机光泽点 | 作物有光泽（白色覆盖层 10% 透明度） |
| **贫瘠** | `#BDB76B` | — | 减少草皮纹理，显得稀疏 | 作物生长缓慢（视觉上缩小 20%） |
| **肥沃** | `#3D2B1F` | `#8B4513` | 5–8 个有机质颗粒 | 作物发光（边缘高光 `#FFD700`） |

### 3.2 土壤纹理绘制算法

```javascript
// 干燥土壤裂纹（随机 2-3 条）
function drawDryCracks(ctx, x, y, tileSize) {
  const crackCount = 2 + Math.floor(Math.random() * 2);
  ctx.strokeStyle = '#8B7355';
  ctx.lineWidth = 1;
  for (let i = 0; i < crackCount; i++) {
    const startX = x + Math.random() * tileSize;
    const startY = y + Math.random() * tileSize;
    ctx.beginPath();
    ctx.moveTo(startX, startY);
    ctx.lineTo(startX + (Math.random() - 0.5) * 8, startY + (Math.random() - 0.5) * 8);
    ctx.stroke();
  }
}

// 湿润土壤光泽点（随机 3-5 个）
function drawWetShine(ctx, x, y, tileSize) {
  const shineCount = 3 + Math.floor(Math.random() * 3);
  ctx.fillStyle = '#6B8E23';
  for (let i = 0; i < shineCount; i++) {
    const px = x + Math.random() * tileSize;
    const py = y + Math.random() * tileSize;
    ctx.fillRect(px, py, 1, 1);
  }
}

// 肥沃土壤有机质颗粒（随机 5-8 个）
function drawFertileParticles(ctx, x, y, tileSize) {
  const particleCount = 5 + Math.floor(Math.random() * 4);
  ctx.fillStyle = '#8B4513';
  for (let i = 0; i < particleCount; i++) {
    const px = x + Math.random() * tileSize;
    const py = y + Math.random() * tileSize;
    ctx.fillRect(px, py, 1, 1);
  }
}
```

### 3.3 作物状态叠加效果

| 土壤状态 | 作物叠加效果 | 实现方式 |
|---------|-------------|---------|
| 干燥 | 偏黄 | `ctx.filter = 'saturate(0.7) sepia(0.3)'` |

## 4. 粒子效果规范

### 4.1 粒子系统参数

```javascript
// 通用粒子类
class Particle {
  constructor(x, y, color, vx, vy, life) {
    this.x = x;
    this.y = y;
    this.color = color;
    this.vx = vx;      // 水平速度 (px/frame)
    this.vy = vy;      // 垂直速度 (px/frame)
    this.life = life;  // 剩余生命 (frames)
    this.maxLife = life;
  }

  update() {
    this.x += this.vx;
    this.y += this.vy;
    this.vy += 0.1;    // 重力
    this.life--;
  }

  draw(ctx) {
    const alpha = this.life / this.maxLife;
    ctx.fillStyle = this.color + Math.floor(alpha * 255).toString(16).padStart(2, '0');
    ctx.fillRect(this.x, this.y, 2, 2);
  }
}
```

### 4.2 场景粒子配置

| 场景 | 粒子颜色 | 数量 | 持续时间 | 初速度范围 | 重力 |
|------|---------|------|---------|-----------|------|
| **种植** | `#8B6914` | 5–8 | 30 帧（0.5s） | `vx: ±1`, `vy: -1 ~ -2` | 0.1 |
| **浇水** | `#4a9eff` | 3–5 | 48 帧（0.8s） | `vx: ±0.5`, `vy: 1 ~ 2` | 0.05 |
| **收获** | `#FFD700` | 8–12 | 60 帧（1.0s） | `vx: ±2`, `vy: -2 ~ -3` | 0.15 |
| **除虫** | `#90EE90` | 5–8 | 36 帧（0.6s） | `vx: ±1.5`, `vy: -0.5 ~ -1.5` | -0.02（上升） |

### 4.3 粒子生成函数示例

```javascript
function spawnParticles(scene, x, y) {
  const configs = {
    plant: { color: '#8B6914', count: [5, 8], life: 30, vx: 1, vy: -1.5 },
    water: { color: '#4a9eff', count: [3, 5], life: 48, vx: 0.5, vy: 1.5 },
    harvest: { color: '#FFD700', count: [8, 12], life: 60, vx: 2, vy: -2.5 },
    pest: { color: '#90EE90', count: [5, 8], life: 36, vx: 1.5, vy: -1 },
    fertilize: { color: '#8B4513', count: [6, 10], life: 30, vx: 1, vy: -0.5 }
  };

  const cfg = configs[scene];
  const count = cfg.count[0] + Math.floor(Math.random() * (cfg.count[1] - cfg.count[0] + 1));

  for (let i = 0; i < count; i++) {
    particles.push(new Particle(
      x + Math.random() * 8,
      y + Math.random() * 8,
      cfg.color,
      (Math.random() - 0.5) * cfg.vx * 2,
      cfg.vy + (Math.random() - 0.5),
      cfg.life
    ));
  }
}
```

```javascript
class Raindrop {
  constructor(canvasWidth) {
    this.x = Math.random() * canvasWidth;
    this.y = -4;

  }

  update() {
    this.y += this.speed;
  }

    ctx.fillStyle = '#4a9eff';
    ctx.fillRect(this.x, this.y, 2, this.length);
  }
}
```

```javascript
function speak(text, tone = 'normal') {
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = 'zh-CN';

  const toneSettings = {
    normal:  { rate: 1.0, pitch: 1.0 },
    happy:   { rate: 1.1, pitch: 1.2 },
    gentle:  { rate: 0.9, pitch: 0.9 },
    excited: { rate: 1.2, pitch: 1.3 },
    relaxed: { rate: 1.0, pitch: 0.95 },
    satisfied: { rate: 0.95, pitch: 1.0 },
    urgent:  { rate: 1.15, pitch: 1.25 }
  };

  const setting = toneSettings[tone] || toneSettings.normal;
  utterance.rate = setting.rate;
  utterance.pitch = setting.pitch;

  speechSynthesis.speak(utterance);
}
```
